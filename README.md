# Tingeling Frisør – nettside

Demo-nettside for Tingeling Frisør, frisørsalong på Vestkollen i Kristiansand. Laget av Taxman.

- `index.html` – hele nettsiden (HTML, CSS og JS i én fil)
- `bilder/` – før & etter-bilder fra salongens Instagram
- `MELDING.md` – meldingen som sendes til salongen

Åpne `index.html` i nettleseren for å se siden.
